# Trivia with OpenAI

A fun and interactive trivia app powered by OpenAI’s GPT model! This app allows users to select a topic of their choice, generate trivia questions dynamically, and test their knowledge. Perfect for learning new things, challenging friends, or just having fun!

Give it a try here: https://cassianebel.github.io/trivia-with-openai/

## 🚀 Features

- Dynamic Question Generation: Leverages OpenAI’s API to create unique trivia questions for any topic you choose.
- Customizable Features: Enter any topic, choose your difficulty level and number of questions then watch the app generate engaging trivia tailored to your choices.
- Interactive Gameplay: Answer questions directly in the app and see if your score and the answers upon completion.
- Educational & Fun: Great for learning and testing your knowledge in a variety of subjects.

## 👩‍💻 Technologies Used

- Frontend: React, Vite
- Styling: TailwindCSS
- API: OpenAI API
- Deployment: GitHub Pages
